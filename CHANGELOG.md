# Changelog

## 0.1.0 - 2026-06-20

### Added

- Initialized the Python 3.12 `badactors` package scaffold managed by `uv`.
- Added strict linting, formatting, typing, and test tooling.
- Added CI checks for `uv sync`, Ruff, mypy, and pytest.
- Added the project constitution in `AGENTS.md`.
- Added initial README documentation and a changelog.
- Added Pydantic v2 schemas for the Bad Actors data contract and schema tests.
- Added the model provider protocol, async OpenRouter provider, deterministic mock provider, and provider tests.
